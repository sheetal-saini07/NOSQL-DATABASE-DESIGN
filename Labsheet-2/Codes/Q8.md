# Comparison of MongoDB, Cassandra and Neo4j

## 1. Data Model
- MongoDB: Document database
- Cassandra: Wide-column database
- Neo4j: Graph database

## 2. Storage Structure
- MongoDB: BSON documents
- Cassandra: Rows grouped into partitions
- Neo4j: Nodes, relationships and properties

## 3. Query Method
- MongoDB: MongoDB Query API
- Cassandra: CQL
- Neo4j: Cypher

## 4. Scalability
- MongoDB: Supports sharding
- Cassandra: Supports distributed horizontal scaling
- Neo4j: Supports clustering options

## 5. Suitable Applications
- MongoDB: Student records and content management
- Cassandra: Large distributed datasets
- Neo4j: Social networks and relationship analysis
